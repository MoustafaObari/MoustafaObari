## 📦 Featured Projects <a id="featured-projects"></a>

### ⚙️ Automated Software Deployment Framework (PowerShell)
**The Why:** Developed as a standalone, portable .exe to allow for "plug-and-play" deployment on any target machine without needing a local script environment.  
**Solution:** Architected a robust wrapper to automate silent installations of **MSI and EXE** installers with built-in logging and automated email status reports.  
**Tech:** PowerShell, WinRM, Windows Forms, SMTP  
🔗 **Repo:** [Software Deployment Tool](https://github.com/MoustafaObari/SoftwareDeploymentTool)

---

### 📊 M365 Compliance & Endpoint Dashboard (PowerShell)
**The Why:** Created to solve the lack of visibility into mobile workforce security posture without manual, time-consuming spreadsheet auditing.  
**Solution:** Built an automated HTML dashboard querying **Microsoft Graph API** to provide real-time visibility into Intune/Entra device compliance.  
**Impact:** Reduced manual compliance reporting time by approximately **90%**.  
**Tech:** PowerShell, Graph API, HTML/CSS  

---

### 🖥️ System Health Monitor (PowerShell Automation)
**The Why:** Designed as a proactive monitoring solution to detect hardware failure or resource exhaustion *before* user impact.  
**Solution:** A lightweight .exe application monitoring CPU, RAM, and Disk health, triggering automated email alerts upon threshold breaches.  
**Result:** Enabled proactive incident response, catching system errors before they were ever reported.  
**Tech:** PowerShell, SMTP, WinForms  
🔗 **Repo:** [System Health Monitor](https://github.com/MoustafaObari/SystemHealthMonitor)
